Аспирация

Оборудование и инструменты для процедуры удаления жидкостей, газов или твердых частиц из организма с помощью вакуума или насосов.

Модуль для отсоса ESM 2

Системный блок аспирации для хирургических платформ ERBE. Обеспечивает подключение совместимых контейнеров, фильтров и расходных материалов линейки ESM 2. Рабочее напряжение: 100–240 В, 50/60 Гц. Интерфейс: ERBE Communication Bus (ECB).

Зажим для крепления на шине-держателе

Пластиковый кронштейн для боковой шины ERBE — компактное крепежное изделие для надежной фиксации оборудования на боковой шине. Используется в составе систем ERBE для аккуратной организации рабочего пространства.

20340-003

Переключающий клапан к ёмкости для отсасываемой жидкости и 2 силиконовых шланга, 300 мм

Кронштейн с переключающим клапаном и двумя силиконовыми шлангами ERBE — комплект аксессуаров для организации аспирационной линии. Материалы допускают очистку в моющем дезинфекторе (до 95 °C) и стерилизацию в автоклаве (до 134 °C).

Силиконовый шланг, 600 мм

Силиконовый шланг 600 мм ERBE — гибкий соединительный элемент для организации аспирационной линии. Используется в составе систем ERBE для удобного подключения компонентов аспирационного контура.

20340-012

Мешок для отсоса секрета 1,5 л с крышкой (в упаковке 30 шт.)

Аспирационный мешок 1,5 л ERBE — одноразовый расходный компонент для сбора отсасываемой жидкости в хирургической практике. Применение: общая хирургия, висцеральная хирургия, хирургия печени, TaTME.

20340-013

Мешок для отсоса секрета 2,5 л с крышкой (в упаковке 30 шт.)

Аспирационный мешок 2,5 л ERBE — одноразовый расходный компонент увеличенного объёма для сбора отсасываемой жидкости. Используется для длительных процедур и операций, где требуется больший запас по сбору жидкости.

20340-100

Мембранный фильтр к модулю для отсоса ESM 2 (упак 10 шт)

Мембранный фильтр ERBE для модуля отсоса ESM 2 — одноразовый расходный компонент, предназначенный для защиты аспирационной системы от загрязнений. Фильтр снижает риск попадания частиц в модуль отсоса.

Контейнер для отсасываемой жидкости 1,5 л

Контейнер для отсасываемой жидкости 1,5 л ERBE — медицинское изделие для безопасного и удобного сбора отсасываемой жидкости в составе аспирационных систем. Используется совместно с аспирационным мешком ERBE.
